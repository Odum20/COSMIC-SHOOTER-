# 🚀 Cosmic Shooter

An action-packed, retro-futuristic 2D arcade space shooter built with **React**, **TypeScript**, **Tailwind CSS**, and **Tone.js**. Defend the galaxy from waves of alien ships and asteroids, collect powerups, unleash special attacks, and achieve the high score!

---

## ✨ Features

- **Retro Arcade Action**: Smooth HTML5 Canvas gameplay featuring particle explosions, laser projectiles, enemy formations, and epic boss encounters.
- **Dual Control Systems**:
  - **Touch Mode (Default)**: On-screen floating D-pad (left) and action buttons for Shooting and Special abilities (right) designed specifically for mobile and touchscreens.
  - **Keyboard Mode**: Traditional desktop controls (WASD/Arrow keys, Space/Z to shoot, X for special, Esc to pause). Toggleable instantly from the main or pause menus.
- **Immersive Sound Engine**: Dynamic retro sound effects powered by **Tone.js** (laser fire, explosions, powerup pickups, special abilities).
- **Responsive UI & Overlays**: Fully responsive layout optimized for mobile portrait/landscape and desktop viewports, with adaptive modal panels and smooth transitions.
- **Powerups & Progression**: Collect coins, energy bars, shields, weapon upgrades, and special bombs as you progress through increasing difficulty levels.

---

## 🕹️ Controls

### Keyboard Mode
- **Move**: `W`, `A`, `S`, `D` or `Arrow Keys`
- **Shoot**: `Spacebar` or `Z`
- **Special Attack**: `X`
- **Pause / Resume**: `Escape`

### Touch Mode
- On-screen D-pad joystick / directional buttons on the bottom-left.
- **SHOOT** and **SPEC** touch buttons on the bottom-right.

---

## 🛠️ Tech Stack

- **Frontend**: React 18+, Vite, TypeScript, Tailwind CSS
- **Audio Synthesis**: Tone.js
- **Animation**: HTML5 Canvas requestAnimationFrame loop

## 🚀 Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/your-username/cosmic-shooter.git
   cd cosmic-shooter
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```
